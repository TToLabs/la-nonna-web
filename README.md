# La Nonna Restaurante · Delivery La Nonna — web pública

Copia pública de la **web** de las apps de pedidos de La Nonna (Luis Thayer Ojeda 95, Local 2, Providencia):

- `cliente/` — app del cliente: menú de hoy, pedido, pago, seguimiento y cuenta.
- `admin/` — app del local: tablero de 3 pasos, menú semanal, clientes, pantallas con QR y configuración.
- `pantalla/` — pantalla compartida por paso (cocina, despacho) que abre el QR.

Las páginas necesitan el servidor de La Nonna (API) para funcionar; aquí solo está la parte visible.
Las APK de Android se publican como descargas en **Releases**.

El código del servidor, los datos y la documentación interna están en el repositorio privado.
